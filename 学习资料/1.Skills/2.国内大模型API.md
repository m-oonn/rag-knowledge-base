# Day 7：国内大模型 API 调用

> 国内大模型（DeepSeek、月之暗面 Moonshot、零一万物等）普遍兼容 OpenAI 格式。
> 学会一个，其他的只需要换 base_url 和 api_key。
> 好处：延迟低、价格便宜、部分有免费额度。

---

## 一、为什么要学国内大模型？

| | Claude API | 国内大模型 |
|--|-----------|-----------|
| 延迟 | 较高（海外服务器）| 低（国内服务器）|
| 价格 | 较贵 | 便宜，部分免费 |
| 网络 | 可能需要代理 | 直连 |
| 质量 | 顶级 | DeepSeek 接近顶级 |
| 面试 | 加分项 | 国内公司更看重 |

**策略**：开发阶段用国内 API（便宜快速），生产环境按需求选择。

## 二、OpenAI 兼容格式

几乎所有国内大模型都兼容 OpenAI 的 API 格式，意味着：
- 用同一个 SDK（`openai` 库）
- 同样的代码结构
- 只需要改 `base_url` 和 `api_key`

```python
from openai import OpenAI

# Claude 不兼容这个格式，但 DeepSeek / Moonshot / 零一万物 都兼容
client = OpenAI(
    api_key="你的key",
    base_url="https://api.deepseek.com",  # 只需改这一行
)
```

## 四、Messages 格式对比

```python
# Claude 格式（Anthropic SDK）
response = anthropic_client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=1024,
    system="你是助手",
    messages=[{"role": "user", "content": "你好"}],
)
answer = response.content[0].text

# OpenAI 兼容格式（DeepSeek/Moonshot 等）
response = openai_client.chat.completions.create(
    model="deepseek-chat",
    max_tokens=1024,
    messages=[
        {"role": "system", "content": "你是助手"},  # system 放在 messages 里！
        {"role": "user", "content": "你好"},
    ],
)
answer = response.choices[0].message.content
```

**关键区别**：
- Claude: `system` 是单独参数，回答在 `response.content[0].text`
- OpenAI格式: `system` 放在 messages 列表里，回答在 `response.choices[0].message.content`
