# Day 12：文本 Embedding

> Embedding 是 RAG 的心脏 —— 把文字变成数字，让计算机理解语义。
> 今天学会用 sentence-transformers 在本地免费生成高质量向量。

---

## 一、Embedding 模型选择

| 模型 | 维度 | 语言 | 大小 | 推荐场景 |
|------|------|------|------|---------|
| all-MiniLM-L6-v2 | 384 | 英文为主 | 80MB | 英文项目、快速测试 |
| paraphrase-multilingual-MiniLM-L12-v2 | 384 | 多语言 | 420MB | 多语言项目 |
| **mofanke/acge_text_embedding** | 1024 | 中文 | ~400MB | 中文项目 |
| BAAI/bge-base-zh-v1.5 | 768 | 中文 | 400MB | **中文RAG推荐** |
| nomic-embed-text (Ollama) | 768 | 多语言 | 274MB | 用Ollama跑 |

**你的项目推荐**：bge-base-zh-v1.5（中文效果好）或 all-MiniLM-L6-v2（轻量快速）

## 二、sentence-transformers 用法

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer("all-MiniLM-L6-v2")

# 单条文本
vector = model.encode("Python是编程语言")
# vector.shape = (384,)

# 批量文本
vectors = model.encode(["文本1", "文本2", "文本3"])
# vectors.shape = (3, 384)
```

```python
import requests
```

## 四、和 Chroma 集成


## 五、面试常问

1. **Embedding 是什么？** → 把文本映射到固定维度的向量空间，语义相近的文本向量距离近
2. **为什么不用 TF-IDF？** → TF-IDF 是词袋模型，不理解语义；Embedding 基于深度学习，能捕捉语义相似性
3. **维度越高越好吗？** → 不一定，高维更精确但更慢更耗内存，384-768 维通常足够
4. **怎么选 Embedding 模型？** → 根据语言（中文选 bge-zh）、速度（轻量选 MiniLM）、场景选择
