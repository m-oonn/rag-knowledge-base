---

## 一、这个系统做什么？

mini_rag.py 是一个 **完整的、单文件的 RAG 问答系统**：

1. 加载 .md 和 .txt 文档
2. 分割文本为 chunks
3. 用 Embedding 向量化（支持 sentence-transformers，自动 fallback 到 TF-IDF）
4. 存入 Chroma 向量数据库（持久化到磁盘）
5. 用户提问 -> 检索相关文档 -> 拼装 Prompt -> LLM 生成回答
6. 回答带引用来源（标注来自哪个文件的第几个 chunk）

## 三、如何运行

### 3.1 安装依赖

```bash
pip install chromadb numpy scikit-learn

# 可选: 安装更好的 Embedding 模型
pip install sentence-transformers

# 可选: 安装 requests（调用 Ollama/DeepSeek LLM）
pip install requests
```

### 3.2 启动

```bash
cd 学习资料/4.RAG/demo
python day16_mini_rag.py
```

### 3.3 首次运行

- 自动在 `sample_docs/` 目录下创建示例文档（Python/FastAPI/RAG 相关内容）
- 自动解析、分割、向量化，存入 Chroma
- 进入交互问答循环

### 3.4 交互命令

```
问题: 什么是RAG？          # 直接输入问题，获得 RAG 回答
问题: /add path/to/doc.md  # 添加新文档到知识库
问题: /status              # 查看知识库状态
问题: /rebuild             # 重建向量索引
问题: quit                 # 退出
```

## 六、面试常问

### Q: 描述一下你项目中 RAG 的完整流程？

> 1. 文档加载：支持 MD/TXT/PDF，使用对应解析库读取纯文本
> 2. 文本分割：RecursiveCharacterTextSplitter，chunk_size=500，overlap=100
> 3. 向量化：使用 sentence-transformers 生成 Embedding
> 4. 存储：Chroma 向量数据库持久化存储
> 5. 检索：用户问题向量化后在 Chroma 做 similarity_search，取 Top-K
> 6. 生成：把检索到的文档和问题组装成 Prompt，交给 LLM 生成回答
> 7. 输出：回答附带引用来源，用户可追溯

> 我先用 mini_rag 原型验证了整个流程可行，再逐步添加前端和优化策略。
