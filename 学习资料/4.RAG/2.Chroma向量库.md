## 一、Chroma 是什么？

轻量级、Python 原生的嵌入式向量数据库。不需要单独部署服务，`pip install chromadb` 就能用。

### 1.1 和其他向量库对比

| 数据库 | 部署方式 | 适合场景 | 学习成本 |
|--------|---------|---------|---------|
| **Chroma** | 嵌入式(pip install) | 中小项目、学习 | **最低** |
| FAISS | 嵌入式(Facebook) | 纯检索、研究 | 中 |
| Pinecone | 云服务 | 生产环境 | 中 |
| Milvus | 分布式部署 | 大规模数据 | 高 |

### 1.2 核心概念

```
Collection（集合）= 一个"表"
  ├── documents: 原始文本（可选）
  ├── embeddings: 向量（必须）
  ├── metadatas: 元数据（来源、日期等）
  └── ids: 唯一标识
```

## 二、基本操作

### 2.1 创建和添加

```python
import chromadb

client = chromadb.Client()  # 内存模式
collection = client.create_collection("my_docs")

collection.add(
    ids=["doc1", "doc2"],
    documents=["Python是编程语言", "FastAPI是Web框架"],
    metadatas=[{"source": "wiki"}, {"source": "docs"}],
)
```

### 2.2 查询

```python
results = collection.query(
    query_texts=["什么是Python"],
    n_results=3,
)
# results["documents"] = 最相似的文档
# results["distances"] = 距离（越小越相似）
# results["metadatas"] = 元数据
```

### 2.3 元数据过滤

```python
results = collection.query(
    query_texts=["Web开发"],
    n_results=5,
    where={"source": "docs"},           # 精确匹配
    where_document={"$contains": "API"}, # 文档包含关键词
)
```

### 2.4 更新和删除

```python
collection.update(ids=["doc1"], documents=["Python是高级编程语言"])
collection.delete(ids=["doc2"])
```

### 2.5 持久化

```python
# 存到磁盘
client = chromadb.PersistentClient(path="./chroma_data")
collection = client.get_or_create_collection("my_docs")
# 数据自动保存，重启后还在
```

## 三、距离度量

| 度量 | 公式 | 特点 | Chroma 参数 |
|------|------|------|------------|
| 余弦距离 | 1-cos(A,B) | 不受向量长度影响 | `cosine`（默认）|
| L2 距离 | 欧几里得距离 | 受长度影响 | `l2` |
| 内积 | 点积 | 需要归一化 | `ip` |

## 四、面试常问

1. **为什么选 Chroma？** → 嵌入式、Python原生、不需额外部署、API简洁、和LangChain集成好
2. **Chroma 怎么持久化？** → PersistentClient(path=) 自动存盘
3. **向量检索的时间复杂度？** → Chroma 用 HNSW 算法，近似最近邻，O(log n)
4. **元数据过滤有什么用？** → 在向量检索基础上加条件过滤，如只搜某个来源的文档
