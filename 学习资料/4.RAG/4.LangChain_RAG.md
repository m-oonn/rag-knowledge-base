# Day 13：LangChain RAG

> LangChain 是把 RAG 各个组件串联起来的"胶水框架"。今天学会用它快速搭建 RAG 流水线。

---

## 一、LangChain 在 RAG 中的角色

```
你手动实现（Day 10-12 学的）：
  读文件 → 手动分割 → 手动Embedding → 手动存Chroma → 手动查询 → 手动拼Prompt

LangChain 帮你做的：
  TextLoader → RecursiveCharacterTextSplitter → Chroma.from_documents → retriever.invoke → RetrievalQA
```

LangChain 不是"魔法"，它只是封装了你已经学过的每一步。

## 二、核心组件

| 组件 | 作用 | 你学过的等价物 |
|------|------|-------------|
| Document Loaders | 读取文件 | `open()` 读文件 |
| Text Splitters | 分割文本 | Day 10 手写的 chunk 函数 |
| Embeddings | 文本→向量 | Day 12 的 sentence-transformers |
| Vector Stores | 存储/检索向量 | Day 11 的 Chroma |
| Retrievers | 检索接口 | `collection.query()` |
| Chains | 串联各步骤 | 你手动写的函数调用链 |

## 三、关键 API

### 3.1 加载文档

```python
from langchain_community.document_loaders import TextLoader
loader = TextLoader("file.md", encoding="utf-8")
docs = loader.load()  # 返回 [Document(page_content=..., metadata=...)]
```

### 3.2 分割文本

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=100)
chunks = splitter.split_documents(docs)
```

### 3.3 创建向量库

```python
from langchain_community.vectorstores import Chroma
from langchain_community.embeddings import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")
vectorstore = Chroma.from_documents(chunks, embeddings)
retriever = vectorstore.as_retriever(search_kwargs={"k": 3})
```

### 3.4 构建 RAG Chain

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

prompt = ChatPromptTemplate.from_template("""根据以下文档回答问题：
{context}
问题：{question}""")

chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)
answer = chain.invoke("什么是FastAPI？")
```

## 四、面试常问

1. **LangChain 是什么？** → LLM 应用开发框架，提供文档加载、分割、Embedding、检索、Chain 等组件
2. **RecursiveCharacterTextSplitter 怎么工作？** → 按分隔符优先级递归分割（先\n\n→再\n→再空格→再字符），保持语义完整
3. **LCEL 是什么？** → LangChain Expression Language，用 `|` 管道符串联组件，类似 Unix 管道
