## 四、LangGraph 图结构

```python
from langgraph.graph import StateGraph, END

workflow = StateGraph(DataAnalysisState)

# 节点
workflow.add_node("load_data", load_data_node)
workflow.add_node("plan", planning_node)
workflow.add_node("generate_code", code_gen_node)
workflow.add_node("execute_code", code_exec_node)
workflow.add_node("create_chart", chart_node)
workflow.add_node("write_report", report_node)

# 边
workflow.set_entry_point("load_data")
workflow.add_edge("load_data", "plan")
workflow.add_edge("plan", "generate_code")
workflow.add_edge("generate_code", "execute_code")

# 条件边：执行成功？
workflow.add_conditional_edges("execute_code", check_execution,
    {"success": "create_chart", "retry": "generate_code", "fail": "write_report"})

workflow.add_edge("create_chart", "write_report")
workflow.add_edge("write_report", END)
```

## 五、State 设计

```python
class DataAnalysisState(TypedDict):
    messages: Annotated[list, add_messages]
    file_path: str
    data_summary: str        # 列名+类型+前5行
    user_request: str        # 用户的分析需求
    analysis_plan: list[str] # LLM 生成的分析计划
    generated_code: str      # LLM 生成的 pandas 代码
    code_output: str         # 代码执行结果
    chart_paths: list[str]   # 生成的图表路径
    report: str              # 最终报告
    error_count: int         # 重试计数
```

## 九、面试常问

1. **你的数据分析 Agent 怎么工作的？** → 用户上传 CSV + 自然语言描述需求 → Agent 读取数据、理解意图、生成 pandas 代码、在沙箱执行、生成图表、输出报告。用 LangGraph 编排整个流程。

2. **Agent 的核心难点是什么？** → 让 LLM 生成可执行的 pandas 代码。需要在 Prompt 中提供准确的数据 schema（列名、类型、样本数据），代码失败时要能自修复。

3. **你怎么保证代码执行安全？** → exec() 沙箱 + 白名单模块（只允许 pandas/numpy/matplotlib）+ 超时控制 + 关键词过滤（禁止 os/subprocess）。

4. **多轮追问怎么实现？** → LangGraph State 中保存 messages 对话历史和之前的分析结果。用户追问时 LLM 能看到上下文，在之前的基础上继续分析。

5. **你的 Agent 和 ChatGPT 的 Code Interpreter 有什么区别？** → 原理相同（LLM→代码→执行→结果），但 ChatGPT 是通用的，我的 Agent 专门针对数据分析场景优化了 Prompt 和工具链。
