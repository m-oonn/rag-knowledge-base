## 二、CSV 读取（最常用）

### 2.1 编码自动检测

中文 CSV 文件可能是 utf-8 或 gbk 编码，直接读经常报 UnicodeDecodeError：

```python
def read_csv_smart(file_path: str) -> pd.DataFrame:
    """自动检测编码读取 CSV"""
    encodings = ["utf-8", "gbk", "gb2312", "latin-1"]
    for enc in encodings:
        try:
            return pd.read_csv(file_path, encoding=enc)
        except UnicodeDecodeError:
            continue
    raise ValueError(f"Cannot decode {file_path} with any encoding")
```

### 2.2 大文件分块读取

```python
# 文件太大时（>100MB），分块处理
chunks = pd.read_csv("big_file.csv", chunksize=10000)
for chunk in chunks:
    process(chunk)  # 每次只加载 1 万行

# 只读需要的列
df = pd.read_csv("data.csv", usecols=["date", "revenue", "product"])
```

## 五、文件验证（安全）

```python
import os

MAX_FILE_SIZE = 50 * 1024 * 1024  # 50MB
ALLOWED_EXTENSIONS = {".csv", ".xlsx", ".xls", ".json", ".txt"}
ALLOWED_DIRECTORY = "/app/uploads"  # 只允许在这个目录操作

def validate_file(file_path: str) -> tuple[bool, str]:
    """验证文件的安全性"""
    # 1. 路径遍历检查
    real_path = os.path.realpath(file_path)
    if not real_path.startswith(os.path.realpath(ALLOWED_DIRECTORY)):
        return False, "Path traversal detected"

    # 2. 文件大小检查
    if os.path.getsize(file_path) > MAX_FILE_SIZE:
        return False, f"File too large (max {MAX_FILE_SIZE/1024/1024}MB)"

    # 3. 扩展名检查
    ext = os.path.splitext(file_path)[1].lower()
    if ext not in ALLOWED_EXTENSIONS:
        return False, f"Unsupported file type: {ext}"

    return True, "OK"
```

## 六、文件信息预览工具

```python
def tool_file_info(file_path: str) -> str:
    """Agent 工具：快速预览文件信息"""
    size = os.path.getsize(file_path)
    ext = os.path.splitext(file_path)[1].lower()

    info = f"File: {os.path.basename(file_path)}\n"
    info += f"Size: {size:,} bytes ({size/1024:.1f} KB)\n"
    info += f"Type: {ext}\n"

    if ext == ".csv":
        df = pd.read_csv(file_path, nrows=5)
        info += f"Columns ({len(df.columns)}): {df.columns.tolist()}\n"
        info += f"Preview:\n{df.to_string()}"
    elif ext in (".xlsx", ".xls"):
        xls = pd.ExcelFile(file_path)
        info += f"Sheets: {xls.sheet_names}"

    return info
```

## 七、写分析报告

```python
def tool_write_report(title: str, findings: list[str], save_path: str) -> str:
    """Agent 工具：生成 Markdown 报告"""
    from datetime import datetime

    report = f"# {title}\n\n"
    report += f"**Date**: {datetime.now().strftime('%Y-%m-%d %H:%M')}\n\n"
    report += "## Key Findings\n\n"
    for i, finding in enumerate(findings, 1):
        report += f"{i}. {finding}\n"

    with open(save_path, "w", encoding="utf-8") as f:
        f.write(report)
    return f"Report saved: {save_path}"
```

## 八、面试常问

1. **怎么处理不同编码的文件？** → 依次尝试 utf-8、gbk、gb2312，或用 chardet 库自动检测
2. **文件太大内存不够怎么办？** → chunksize 分块读取，或 usecols 只读需要的列
3. **路径遍历攻击是什么？** → 用户传入 `../../etc/passwd` 试图读取系统文件。防护：realpath 检查是否在允许目录内
4. **Agent 怎么知道文件内容？** → 调用 file_info 工具获取列名/类型/预览，作为 context 发给 LLM
5. **为什么要限制文件大小？** → 防止内存溢出导致服务器崩溃，生产环境通常限制 10-50MB
