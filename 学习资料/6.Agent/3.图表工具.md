## 一、为什么 Agent 需要图表？

数据分析报告中，图表比表格更直观：
- 趋势用折线图 → 一眼看出涨跌
- 对比用柱状图 → 一眼看出大小
- 占比用饼图 → 一眼看出份额

Agent 的图表流程：**LLM 决定图表类型 → 生成 matplotlib 代码 → 沙箱执行 → 保存图片 → 返回路径**

## 二、matplotlib 核心用法

### 2.1 非交互后端（服务器必需）

```python
import matplotlib
matplotlib.use('Agg')  # 不弹窗，直接保存文件（服务器没有显示器）
import matplotlib.pyplot as plt
```

**面试被问"为什么用 Agg"**：Agent 部署在服务器上没有 GUI 环境，Agg 后端直接渲染到文件。

### 2.2 中文字体配置

```python
# Windows
plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei']
# Mac
plt.rcParams['font.sans-serif'] = ['Arial Unicode MS', 'PingFang SC']
# 通用
plt.rcParams['axes.unicode_minus'] = False  # 解决负号 "-" 显示为方块
```

不配置中文字体的话，中文标题会显示为 "□□□□"。

### 2.3 基本模式（所有图表通用）

```python
fig, ax = plt.subplots(figsize=(10, 6))  # 创建画布和坐标轴
ax.plot(x, y)                             # 绑定数据
ax.set_title("标题")                       # 设置标题
ax.set_xlabel("X轴")                      # X轴标签
ax.set_ylabel("Y轴")                      # Y轴标签
ax.grid(True, alpha=0.3)                  # 网格线
plt.tight_layout()                        # 自动调整间距
plt.savefig("chart.png", dpi=100)         # 保存文件
plt.close()                               # 关闭释放内存（重要！）
```

**plt.close() 很重要**：不关闭会内存泄漏，Agent 连续生成多张图时会崩溃。

## 三、5 种常用图表

### 3.1 折线图（趋势分析）

```python
months = ['1月', '2月', '3月', '4月', '5月', '6月']
revenue = [45000, 52000, 48000, 61000, 58000, 65000]

fig, ax = plt.subplots(figsize=(10, 6))
ax.plot(months, revenue, 'b-o', linewidth=2, markersize=8, label='Revenue')
ax.fill_between(range(len(months)), revenue, alpha=0.1)  # 面积填充
ax.set_title('Monthly Revenue Trend')
ax.legend()
```

### 3.2 柱状图（分类对比）

```python
products = ['Product A', 'Product B', 'Product C']
values = [120000, 95000, 78000]
colors = ['#2196F3', '#4CAF50', '#FF9800']

fig, ax = plt.subplots(figsize=(8, 5))
bars = ax.bar(products, values, color=colors)
# 在柱顶显示数值
for bar, val in zip(bars, values):
    ax.text(bar.get_x() + bar.get_width()/2, bar.get_height(),
            f'{val:,}', ha='center', va='bottom')
```

### 3.3 饼图（占比分布）

```python
regions = ['East', 'West', 'North', 'South']
shares = [35, 28, 22, 15]

fig, ax = plt.subplots(figsize=(8, 8))
ax.pie(shares, labels=regions, autopct='%1.1f%%',
       startangle=90, explode=(0.05, 0, 0, 0))  # 突出第一块
```

### 3.4 散点图（相关性）

```python
ax.scatter(df['quantity'], df['revenue'], alpha=0.6, c='steelblue')
ax.set_xlabel('Quantity')
ax.set_ylabel('Revenue')
```

### 3.5 组合图（双Y轴）

```python
fig, ax1 = plt.subplots(figsize=(10, 6))
ax2 = ax1.twinx()  # 共享X轴的第二个Y轴
```

## 四、封装为 Agent 工具

```python
def create_chart(data, chart_type, title, x_col=None, y_col=None, save_path="chart.png"):
    """
    Agent 图表工具。

    输入: data(dict/DataFrame), chart_type, title
    输出: 保存的文件路径

    Agent Prompt 中的工具描述:
    "create_chart: 创建图表。参数: data(数据), chart_type(line/bar/pie), title(标题)"
    """
    import matplotlib
    matplotlib.use('Agg')
    import matplotlib.pyplot as plt
    plt.rcParams['font.sans-serif'] = ['SimHei', 'Microsoft YaHei', 'DejaVu Sans']
    plt.rcParams['axes.unicode_minus'] = False

    fig, ax = plt.subplots(figsize=(10, 6))

    if isinstance(data, dict):
        x, y = data.get("x", []), data.get("y", [])
    else:
        x, y = data[x_col], data[y_col]

    if chart_type == "line":
        ax.plot(x, y, 'b-o', linewidth=2)
    elif chart_type == "bar":
        ax.bar(x, y, color='steelblue')
    elif chart_type == "pie":
        ax.pie(y, labels=x, autopct='%1.1f%%')
    elif chart_type == "scatter":
        ax.scatter(x, y, alpha=0.6)

    ax.set_title(title, fontsize=14)
    if chart_type != "pie":
        ax.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.savefig(save_path, dpi=100, bbox_inches='tight')
    plt.close()  # 关闭防内存泄漏
    return save_path
```

## 五、Agent 如何选择图表类型

| 用户表达 | 图表类型 | 判断依据 |
|---------|---------|---------|
| "趋势""变化""走势" | 折线图 | 时间序列数据 |
| "对比""比较""排名" | 柱状图 | 分类数据 |
| "占比""分布""份额" | 饼图 | 比例数据（≤6个类别）|
| "关系""相关""散布" | 散点图 | 两个数值列 |
| "分布""频率" | 直方图 | 单个数值列 |

Agent 的 LLM 根据用户描述和数据特征自动选择。

## 六、面试常问

1. **Agent 怎么生成图表？** → LLM 生成 matplotlib 代码，在 Agg 后端沙箱执行，保存为 PNG，返回文件路径
2. **为什么用 Agg backend？** → 服务器无 GUI，Agg 直接渲染到文件不弹窗
3. **中文显示乱码怎么解决？** → 设置 rcParams 的 font.sans-serif 为 SimHei/YaHei + axes.unicode_minus=False
4. **plt.close() 的作用？** → 释放 figure 对象内存。Agent 连续生成多张图，不 close 会内存泄漏
5. **怎么选择图表类型？** → 根据数据类型：时间序列→折线，分类对比→柱状，占比→饼图。LLM 可以自动判断
