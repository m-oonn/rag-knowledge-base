### 1.2 数据概览（给 LLM 看的上下文）

```python
df.shape          # (行数, 列数)
df.columns.tolist()  # 列名列表
df.dtypes         # 每列的数据类型
df.head(5)        # 前5行预览
df.describe()     # 数值列的统计摘要（均值/标准差/最大最小等）
df.info()         # 内存占用和非空值数
df.isnull().sum()  # 每列缺失值数量
```

**关键**：Agent 在分析数据之前，先把这些信息作为 context 发给 LLM，让 LLM 了解数据结构后再生成分析代码。

### 1.3 过滤和选择

```python
df[df["revenue"] > 10000]                # 单条件
df[(df["region"] == "East") & (df["revenue"] > 5000)]  # 多条件
df[df["product"].isin(["A", "B"])]       # 包含
df.nlargest(10, "revenue")               # Top 10
df.nsmallest(5, "cost")                  # Bottom 5
```

### 1.4 分组聚合（Agent 最常生成的操作）

```python
# 单列分组
df.groupby("product")["revenue"].sum()

# 多列分组
df.groupby(["region", "product"])["revenue"].mean()

# 多聚合
df.groupby("product").agg({
    "revenue": ["sum", "mean", "count"],
    "quantity": "sum",
})

# 透视表
pd.pivot_table(df, values="revenue", index="region", columns="product", aggfunc="sum")
```

### 1.5 时间序列（趋势分析必备）

```python
df["date"] = pd.to_datetime(df["date"])        # 转日期类型
```

### 1.6 计算新列


## 二、为 Agent 封装工具函数

```python
def tool_data_overview(df: pd.DataFrame) -> str:
    """工具：数据概览（Agent 首先调用这个了解数据）"""
    info = f"Shape: {df.shape[0]} rows x {df.shape[1]} columns\n"
    info += f"Columns: {df.columns.tolist()}\n"
    info += f"Types:\n{df.dtypes.to_string()}\n"
    info += f"Sample:\n{df.head(3).to_string()}\n"
    info += f"Stats:\n{df.describe().to_string()}"
    return info

def tool_group_analysis(df, group_col, value_col, agg="sum") -> str:
    """工具：分组聚合"""
    result = df.groupby(group_col)[value_col].agg(agg)
    return result.sort_values(ascending=False).to_string()

def tool_trend_analysis(df, date_col, value_col) -> str:
    """工具：时间趋势"""
    df[date_col] = pd.to_datetime(df[date_col])
    monthly = df.set_index(date_col)[value_col].resample("ME").sum()
    trend = "upward" if monthly.iloc[-1] > monthly.iloc[0] else "downward"
    return f"Monthly trend ({trend}):\n{monthly.to_string()}"

def tool_filter_data(df, column, operator, value) -> str:
    """工具：条件过滤"""
    ops = {">=": "ge", "<=": "le", ">": "gt", "<": "lt", "==": "eq"}
    filtered = df[getattr(df[column], ops[operator])(value)]
    return f"Filtered: {len(filtered)} rows\n{filtered.head(10).to_string()}"
```

## 三、Agent 数据分析的典型模式

```
用户: "分析各产品的销售情况"

Agent 执行流程:
  1. tool_data_overview(df) → 了解有哪些列
  2. 判断: "product" 列存在，"revenue" 是数值列
  3. tool_group_analysis(df, "product", "revenue", "sum") → 各产品总销售
  4. 生成分析代码:
     df.groupby("product").agg({"revenue": ["sum","mean"], "quantity": "sum"})
  5. safe_exec(code) → 执行并捕获结果
  6. LLM 解读结果 → "Product A 销售额最高..."
```

## 四、数据预览设计（给 LLM 的 context）

```python
def build_data_context(df: pd.DataFrame, max_rows: int = 5) -> str:
    """构建给 LLM 的数据描述（放在 Prompt 里）"""
    context = f"""Available data:
- Rows: {df.shape[0]}, Columns: {df.shape[1]}
- Columns and types:
{chr(10).join(f'  {col}: {dtype}' for col, dtype in df.dtypes.items())}
- Sample data (first {max_rows} rows):
{df.head(max_rows).to_string()}
- Numeric summary:
{df.describe().to_string()}"""
    return context
```

这段 context 放在 Agent Prompt 的 `## 当前数据` 部分，让 LLM 知道数据长什么样再生成代码。

## 五、面试常问

1. **Agent 怎么分析数据？** → LLM 先看数据概览（shape/columns/sample），理解结构后生成 pandas 代码，在沙箱中执行
2. **为什么用 pandas？** → Python 数据分析标准库，LLM 训练数据中有大量 pandas 示例，生成代码质量高
3. **数据太大怎么办？** → pd.read_csv(chunksize=10000) 分块读取；只读取需要的列 usecols=["col1","col2"]
4. **怎么让 LLM 生成正确的代码？** → 在 Prompt 中提供数据 schema（列名+类型+前几行），让 LLM 了解数据结构
5. **缺失值怎么处理？** → 在数据概览中告知 LLM 缺失情况，让它在代码中加 dropna() 或 fillna()
