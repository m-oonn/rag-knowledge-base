# Day 37：综合练习 - 完整 Agent

> 今天不讲新理论，把 Day 35-36 学的全部整合成一个**可交互的完整 Agent**。
> 这个 Agent 是你项目二（数据分析 Agent）的原型，后面在它基础上扩展。

---

## 一、这个 Agent 做什么？

一个**命令行交互式 AI 助手**，具备：
- 3 个工具：计算器、时间查询、知识库搜索
- 对话记忆：记住之前说过的话
- ReAct 循环：自主决定调用工具还是直接回答
- Verbose 模式：显示 Thought / Action / Observation 轨迹
- 优雅降级：Ollama / DeepSeek / 模拟模式自动切换

## 三、如何运行

```bash
# 安装依赖
pip install langgraph langchain-core langchain-openai python-dotenv

# 方式 1：确保 Ollama 在运行
ollama serve

# 方式 2：配置 DeepSeek API Key
# 在 .env 文件中写入: DEEPSEEK_API_KEY=your_key

# 运行
python day37_simple_agent.py
```

**交互模式**：
```
Agent> 你好！我是 AI 助手。输入问题开始对话，输入 quit 退出。

You> 帮我算一下 123 * 456
  [Thought] 需要使用计算器工具
  [Action]  calculator(expression="123*456")
  [Observation] 计算结果: 123*456 = 56088
Agent> 123 乘以 456 的结果是 56088。

You> 现在几点了？
  [Action]  get_current_time()
  [Observation] 当前时间: 2025年05月15日 14:30:22 (星期四)
Agent> 现在是 2025 年 5 月 15 日下午 2 点 30 分。

You> quit
再见！
```
