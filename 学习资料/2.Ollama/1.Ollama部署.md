## 一、Ollama 是什么？

### 1.1 一句话理解

Ollama = **本地大模型运行器**。把开源模型下载到你电脑上，通过 API 调用，和云端 API 用法一模一样。

### 1.2 为什么需要本地模型？

| | 云端 API（Claude/DeepSeek） | 本地 Ollama |
|--|---------------------------|------------|
| 费用 | 按 token 收费 | **完全免费** |
| 网络 | 需要联网 | **不需要** |
| 速度 | 取决于网络 | 取决于你的硬件 |
| 隐私 | 数据发到云端 | **数据不出本地** |
| 质量 | 顶级 | 够用（7B模型约等于GPT-3.5水平）|
| 调用限制 | 有限流 | **无限制** |

**开发策略**：
- 写代码调试时 → Ollama（免费无限调用）
- 测试效果时 → DeepSeek（便宜质量好）
- 正式演示/上线 → Claude（最强）

### 1.3 硬件要求

| 模型大小 | 最低内存 | 推荐 | 说明 |
|---------|---------|------|------|
| 1.5B-3B | 4GB RAM | 8GB | 很快但质量一般 |
| **7B** | **8GB RAM** | **16GB** | **推荐！质量和速度平衡** |
| 13B | 16GB RAM | 32GB | 质量好但较慢 |
| 70B | 需要GPU | 64GB+ | 接近商用水平 |

你的电脑有 NVIDIA GPU 的话，Ollama 会自动用 GPU 加速。

## 二、安装 Ollama

### 2.1 Windows 安装

1. 打开 https://ollama.com/download
2. 下载 Windows 版安装包
3. 双击安装（一路 Next）
4. 安装完成后，打开终端验证：

```bash
ollama --version
# 应该输出: ollama version 0.x.x
```

### 2.2 拉取模型

```bash
# 拉取 qwen2.5:7b（推荐，中文能力强，约4.4GB）
ollama pull qwen2.5:7b

# 其他可选模型：
# ollama pull llama3.2:3b     # Meta的模型，3B小巧快速
# ollama pull mistral:7b      # 欧洲的模型，英文强
# ollama pull deepseek-r1:7b  # DeepSeek推理模型
```

### 2.3 验证运行

```bash
# 命令行直接对话
ollama run qwen2.5:7b

# 输入问题测试
>>> 你好，用一句话介绍Python
# 等待回答...
# 输入 /bye 退出
```

### 2.4 Ollama 作为 API 服务

Ollama 安装后自动启动 API 服务：
- 地址：`http://localhost:11434`
- 完全兼容 OpenAI 格式（`/v1/chat/completions`）

```bash
# 测试 API 是否可用
curl http://localhost:11434/api/tags
# 应该返回已安装的模型列表
```

## 三、两种调用方式

### 3.1 Ollama 原生 API

```python
import requests

response = requests.post(
    "http://localhost:11434/api/generate",
    json={
        "model": "qwen2.5:7b",
        "prompt": "什么是Python？",
        "stream": False,
    }
)
print(response.json()["response"])
```

### 3.2 OpenAI 兼容模式（推荐！）

Ollama 提供 `/v1` 端点，完全兼容 OpenAI 格式。
这意味着 **Day 7 写的 LLMClient 类不用改一行代码就能调用本地模型！**

```python
from openai import OpenAI

client = OpenAI(
    api_key="ollama",                         # 随便填，Ollama不检查
    base_url="http://localhost:11434/v1",     # 指向本地 Ollama
)

response = client.chat.completions.create(
    model="qwen2.5:7b",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```

**关键点**：和 Day 7 调 DeepSeek 的代码完全一样，只改了 `base_url` 和 `api_key`。

## 四、Ollama 常用命令

| 命令 | 作用 |
|------|------|
| `ollama list` | 查看已安装的模型 |
| `ollama pull <model>` | 下载模型 |
| `ollama run <model>` | 命令行对话 |
| `ollama rm <model>` | 删除模型（释放磁盘）|
| `ollama show <model>` | 查看模型详情 |
| `ollama ps` | 查看正在运行的模型 |

## 五、性能优化

### 5.1 GPU 加速

如果你有 NVIDIA GPU，Ollama 会自动使用 CUDA 加速。验证方法：

```bash
ollama ps
# 如果 PROCESSOR 列显示 GPU，说明在用 GPU
```

### 5.2 模型选择建议

| 场景 | 推荐模型 | 原因 |
|------|---------|------|
| 日常开发调试 | `qwen2.5:7b` | 中文好，速度适中 |
| 快速测试 | `qwen2.5:3b` | 更快，质量够用 |
| 代码生成 | `deepseek-coder-v2:latest` | 专门优化了代码能力 |
| 内存不够 | `qwen2.5:1.5b` | 1.5B 模型，占用最小 |
