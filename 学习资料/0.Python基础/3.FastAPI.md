## 一、FastAPI 是什么？

### 1.1 一句话理解

FastAPI = **用 Python 写 API 接口的框架**，自带数据验证、自动文档、异步支持。

### 1.2 为什么选 FastAPI？

| 特性 | Flask | Django | FastAPI |
|------|-------|--------|---------|
| 学习曲线 | 低 | 高 | 中 |
| 性能 | 一般 | 一般 | **极高**（异步）|
| 自动文档 | ❌ | ❌ | ✅ Swagger + ReDoc |
| 数据验证 | 手动写 | 手动写 | ✅ Pydantic 自动 |
| 异步支持 | 需要插件 | 部分 | ✅ 原生支持 |
| AI 项目适合度 | 一般 | 重 | **最适合** |

面试被问"为什么选 FastAPI"：
> FastAPI 原生支持异步，AI 应用需要大量 IO 等待（API调用、数据库查询）；
> Pydantic 自动验证请求数据，减少手写校验代码；
> 自带 Swagger 文档，方便前后端联调。

### 1.3 核心概念

```
用户请求 → FastAPI 路由匹配 → 参数验证(Pydantic) → 执行函数 → 返回响应
                                     ↓ 失败
                              自动返回 422 错误
```

## 二、FastAPI 基础

### 2.1 最小应用

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Hello World"}
```

运行：`uvicorn main:app --reload`
- `main` = 文件名 main.py
- `app` = FastAPI 实例的变量名
- `--reload` = 代码修改后自动重启（开发模式）

### 2.2 自动文档

启动后访问：
- `http://127.0.0.1:8000/docs` → Swagger UI（可以直接测试接口）
- `http://127.0.0.1:8000/redoc` → ReDoc（更漂亮的文档）

这是 FastAPI 最大的卖点之一，**不需要手写 API 文档**。

### 2.3 HTTP 方法

```python
@app.get("/items")       # 查询
@app.post("/items")      # 创建
@app.put("/items/{id}")  # 全量更新
@app.patch("/items/{id}")# 部分更新
@app.delete("/items/{id}")# 删除
```

对应 RESTful API 的 CRUD 操作：
- **C**reate = POST
- **R**ead = GET
- **U**pdate = PUT/PATCH
- **D**elete = DELETE

## 三、请求参数（4种）

### 3.1 路径参数（Path Parameters）

URL 的一部分，用 `{}` 占位：

```python
@app.get("/users/{user_id}")
def get_user(user_id: int):  # 自动转成 int
    return {"user_id": user_id}
# 访问: GET /users/42 → {"user_id": 42}
# 访问: GET /users/abc → 422 错误（不是 int）
```

### 3.2 查询参数（Query Parameters）

URL 中 `?` 后面的参数：

```python
@app.get("/items")
def list_items(skip: int = 0, limit: int = 10, q: str | None = None):
    return {"skip": skip, "limit": limit, "q": q}
# 访问: GET /items?skip=5&limit=20&q=python
# 访问: GET /items → 使用默认值 skip=0, limit=10, q=None
```

### 3.3 请求体（Request Body）

POST/PUT 请求中的 JSON 数据，用 Pydantic 模型接收：

```python
from pydantic import BaseModel

class ItemCreate(BaseModel):
    name: str
    price: float
    description: str | None = None

@app.post("/items")
def create_item(item: ItemCreate):
    return {"name": item.name, "price": item.price}
# 请求体: {"name": "Python书", "price": 59.9}
```

### 3.4 请求头 / Cookie

```python
from fastapi import Header, Cookie

@app.get("/info")
def get_info(
    user_agent: str = Header(default=None),
    token: str = Cookie(default=None),
):
    return {"user_agent": user_agent, "token": token}
```

### 3.5 四种参数的判断规则

```
参数出现在路径 {param} 中？  → 路径参数
参数类型是 Pydantic 模型？   → 请求体
其他基础类型？                → 查询参数
用了 Header()/Cookie()？     → 请求头/Cookie
```

## 四、响应处理

### 4.1 响应模型（控制返回哪些字段）

```python
class UserOut(BaseModel):
    id: int
    name: str
    email: str
    # 注意：没有 password 字段！

class UserInDB(BaseModel):
    id: int
    name: str
    email: str
    password: str  # 数据库里有密码

@app.get("/users/{user_id}", response_model=UserOut)
def get_user(user_id: int):
    user = UserInDB(id=1, name="张三", email="z@test.com", password="secret")
    return user
    # 返回时自动过滤掉 password，只返回 UserOut 中定义的字段
```

### 4.2 状态码

```python
from fastapi import status

@app.post("/items", status_code=status.HTTP_201_CREATED)
def create_item(item: ItemCreate):
    return item

# 常用状态码：
# 200 OK          → 查询成功
# 201 Created     → 创建成功
# 204 No Content  → 删除成功
# 400 Bad Request → 请求错误
# 404 Not Found   → 未找到
# 422 Unprocessable → 数据验证失败（FastAPI自动）
# 500 Server Error → 服务器内部错误
```

### 4.3 直接返回自定义响应

```python
from fastapi.responses import JSONResponse, HTMLResponse

@app.get("/custom")
def custom_response():
    return JSONResponse(
        status_code=200,
        content={"message": "自定义响应"},
        headers={"X-Custom-Header": "hello"}
    )
```

## 五、依赖注入（Depends）—— FastAPI 的核心设计

### 5.1 什么是依赖注入？

**一句话理解**: 你告诉 FastAPI "我需要 XX"，它自动帮你准备好。

```python
from fastapi import Depends

# 依赖函数：准备数据库连接
def get_db():
    db = Database()
    try:
        yield db  # 把 db 交给路由函数用
    finally:
        db.close()  # 路由执行完后自动关闭

# 路由函数：声明"我需要 db"
@app.get("/users")
def get_users(db = Depends(get_db)):
    # FastAPI 自动调用 get_db()，把 db 传给你
    return db.query("SELECT * FROM users")
```

### 5.2 为什么需要依赖注入？

不用 Depends 的话：
```python
@app.get("/users")
def get_users():
    db = Database()          # 每个路由都要手动创建
    try:
        result = db.query()
        return result
    finally:
        db.close()           # 每个路由都要手动关闭

@app.get("/items")
def get_items():
    db = Database()          # 重复代码！
    try:
        result = db.query()
        return result
    finally:
        db.close()           # 重复代码！
```

用了 Depends：**一次定义，所有路由复用**。

### 5.3 常见依赖注入场景

```python
# 1. 数据库连接
def get_db():
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

# 2. 用户认证
def get_current_user(token: str = Header()):
    user = verify_token(token)
    if not user:
        raise HTTPException(status_code=401, detail="未登录")
    return user

# 3. 分页参数
def pagination(skip: int = 0, limit: int = 10):
    return {"skip": skip, "limit": limit}

# 使用多个依赖
@app.get("/my-items")
def get_my_items(
    user = Depends(get_current_user),
    page = Depends(pagination),
    db = Depends(get_db),
):
    return db.query(Item).filter(owner=user.id).offset(page["skip"]).limit(page["limit"])
```

## 六、中间件（Middleware）

### 6.1 什么是中间件？

**中间件 = 每个请求都要经过的"检查站"**。

```
请求进来 → 中间件A → 中间件B → 路由函数 → 中间件B → 中间件A → 响应返回
```

### 6.2 自定义中间件

```python
import time

@app.middleware("http")
async def add_process_time(request, call_next):
    start = time.time()
    response = await call_next(request)  # 执行实际的路由
    elapsed = time.time() - start
    response.headers["X-Process-Time"] = str(elapsed)
    print(f"[{request.method}] {request.url.path} → {elapsed:.3f}s")
    return response
```

### 6.3 CORS 中间件（前后端分离必需）

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:3000"],  # 前端地址
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

**为什么需要 CORS**: 浏览器安全策略，前端（localhost:3000）和后端（localhost:8000）不同端口，浏览器默认禁止跨域请求。加了 CORS 中间件才能正常通信。

## 七、异常处理

### 7.1 HTTPException

```python
from fastapi import HTTPException

@app.get("/users/{user_id}")
def get_user(user_id: int):
    user = find_user(user_id)
    if not user:
        raise HTTPException(
            status_code=404,
            detail=f"用户 {user_id} 不存在"
        )
    return user
```

### 7.2 全局异常处理

```python
from fastapi.responses import JSONResponse

@app.exception_handler(ValueError)
async def value_error_handler(request, exc):
    return JSONResponse(
        status_code=400,
        content={"error": str(exc), "type": "ValueError"}
    )
```

## 八、文件上传（项目一会用到）

```python
from fastapi import UploadFile, File

@app.post("/upload")
async def upload_file(file: UploadFile = File(...)):
    content = await file.read()
    return {
        "filename": file.filename,
        "size": len(content),
        "content_type": file.content_type,
    }

# 多文件上传
@app.post("/upload-many")
async def upload_files(files: list[UploadFile] = File(...)):
    return [{"filename": f.filename} for f in files]
```

## 九、应用结构（项目中的组织方式）

### 9.1 路由分组（APIRouter）

大项目不能把所有路由写在一个文件里：

```python
# routers/users.py
from fastapi import APIRouter

router = APIRouter(prefix="/users", tags=["用户管理"])

@router.get("/")
def list_users():
    return [...]

@router.get("/{user_id}")
def get_user(user_id: int):
    return {...]

# main.py
from fastapi import FastAPI
from routers import users

app = FastAPI()
app.include_router(users.router)
```

### 9.2 项目目录结构

```
project/
├── main.py              # FastAPI 应用入口
├── routers/             # 路由
│   ├── users.py
│   └── items.py
├── models/              # Pydantic 模型
│   ├── user.py
│   └── item.py
├── services/            # 业务逻辑
│   └── user_service.py
├── database.py          # 数据库连接
└── config.py            # 配置
```

## 十一、面试常问

1. **FastAPI 和 Flask 的区别？** → FastAPI 原生异步、Pydantic自动验证、自动生成文档；Flask 更轻量但需要手动做这些
2. **什么是依赖注入？** → 把函数需要的资源（数据库连接、用户认证等）通过 Depends 声明，FastAPI 自动准备
3. **什么是中间件？** → 每个请求/响应都经过的处理层，适合做日志、计时、CORS等通用逻辑
4. **FastAPI 怎么做数据验证？** → 通过 Pydantic 模型 + 类型注解，自动验证请求参数和体
5. **什么是 CORS？为什么需要？** → 跨域资源共享，前后端分离时浏览器安全策略要求后端允许跨域
