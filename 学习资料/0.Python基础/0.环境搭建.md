## 三、常见问题排查

| 问题 | 解决方案 |
|------|---------|
| pip install 超时 | 加 `-i https://mirrors.aliyun.com/pypi/simple/` |
| pandas 安装失败 | `pip install pandas --only-binary=:all:` |
| 虚拟环境激活失败 | PowerShell 执行: `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| .env 文件被 Git 跟踪 | 先 `git rm --cached .env`，确保 .gitignore 里有 `.env` |
| 包冲突 | 删掉 venv 重建: `rmdir venv /s /q && python -m venv venv` |
