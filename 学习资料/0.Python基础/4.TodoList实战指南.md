## 一、项目需求

做一个待办事项（Todo）管理 API：

| 功能 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 获取所有待办 | GET | /todos | 支持分页、状态过滤、关键词搜索 |
| 获取单个待办 | GET | /todos/{id} | 根据 ID 查询 |
| 创建待办 | POST | /todos | 传入标题、描述、优先级 |
| 更新待办 | PATCH | /todos/{id} | 部分更新（标题/状态/优先级）|
| 删除待办 | DELETE | /todos/{id} | 删除指定待办 |
| 统计信息 | GET | /todos/stats | 已完成/未完成数量统计 |

## 四、学习方式

1. **先通读整个项目代码**（约 20 分钟）
2. **启动项目，在 Swagger 中测试每个接口**（约 30 分钟）
3. **自己尝试加一个功能**（约 60 分钟），比如：
   - 给 Todo 加一个 `tags` 字段（列表类型）
   - 加一个 `GET /todos/search?q=关键词` 全文搜索接口
   - 加一个 `PUT /todos/{id}/toggle` 快速切换完成状态
4. **遇到不懂的回去翻前几天的文档**
